# S/4HANA 低版本（7.50/7.51）信息收集清单

> 用途：M0 版本指纹与能力矩阵的数据源。收集结果直接决定 71 能力在低版本上的
> 裁剪矩阵真值（见 `docs/S4低版本适配规划.md` §2/§3）。
> 全程只读：不写任何表、不改任何配置、不建任何传输。
> 收集完成后把全部输出粘贴回来即可，格式已按机器可解析设计。

## 方式 A（最优）：把低版本连接信息给我，我全权收集

如果目标系统可以给我连接（内网可达），这是最高效的方式——用现有 MCP 服务器
加一个独立连接实例，我通过只读工具直接收集全部条目并自动落档。

需要的连接信息（二选一或都给）：

```ini
# ADT HTTP 面（对应现有 sap-demo.env 的形态）
SAP_URL=https://<host>:<44300 或 00 严格 TLS 端口>
SAP_CLIENT=<client>
SAP_USER=<user>
SAP_PASSWORD=<password>

# 或 RFC 网关面（如果有，M0 指纹探测顺带验证）
RFC_ASHOST=<host>
RFC_SYSNR=<nn>
RFC_CLIENT=<client>
RFC_USER=<user>
RFC_PASSWORD=<password>
```

要求：DEV/沙箱角色系统；用户至少有与 Eclipse ADT 相同的授权（如果 Eclipse 能连
就够了）。所有收集动作仅只读面（discovery/读表/结构查询）。

## 方式 B：ABAP 只读收集报表（有 SAP GUI 即可，5 分钟）

SE38 新建本地程序（包 `$TMP`，命名如 `ZCOLLECT_LOW_RELEASE_FACTS`），粘贴以下
全部内容，激活后直接执行（F8），把输出列表整屏复制回来。
程序只做 SELECT 标准表和 FUNCTION_EXISTS，无任何写入。

> v2 健壮版说明（2026-10-15 修订）：v1 因低版本 CVERS 无 `SPLEVEL` 列、`DDLSRC`
> 表不存在而编译失败。v2 改为全动态容错：表存在性先经 DD02L 验证（不存在本身
> 就是收集结果，照常输出 NOT_EXIST），CVERS 用 SELECT * 全字段 + 动态读列，
> 任何版本结构差异都不会再导致编译错误。
> v2.1（同日二修）：`FUNCTION_EXISTS` 调用改为只用 EXCEPTIONS 判定——v2 曾因
> 误用不存在的 `FOUND` IMPORTING 参数运行时 dump，EXCEPTIONS 面全版本稳定。
> v3（同日三修）：输出改为一键复制——全文同步收集到内表，程序结尾写入 Windows
> 剪贴板（收到提示后直接 Ctrl+V 粘贴发送）；剪贴板不可用时回退"另存为"导出 txt；
> 屏幕列表照常输出兜底。

```abap
REPORT zcollect_low_release_facts NO STANDARD PAGE HEADING.
* =====================================================================
* 用途：SAP 低版本（S/4 7.50/7.51 或 ECC）适配评估的只读系统信息收集 v3。
* 范围：仅 SELECT 标准表 + FUNCTION_EXISTS，不写任何数据、不改任何配置。
* 容错：所有表先经 DD02L 验证存在性（不存在 = NOT_EXIST，本身是版本事实）；
*       CVERS 用 SELECT * 全字段 + 动态读列；FUNCTION_EXISTS 只用 EXCEPTIONS。
* 输出：屏幕列表照常；结尾把全文写入 Windows 剪贴板（直接 Ctrl+V 粘贴发送），
*       剪贴板不可用时回退"另存为"对话框导出 txt。
* =====================================================================

DATA: gt_report TYPE STANDARD TABLE OF string,
      gv_line   TYPE string,
      gv_tab    TYPE dd02l-tabname,
      gv_count  TYPE i.

START-OF-SELECTION.

  " ---- 1. 系统指纹：sysid / basis release / 数据库类型 ----
  gv_line = '=== SECTION1_SYSTEM'.            PERFORM emit.
  gv_line = |SYSID={ sy-sysid }|.             PERFORM emit.
  gv_line = |BASIS_RELEASE={ sy-saprl }|.     PERFORM emit.
  gv_line = |DBSYS={ sy-dbsys }|.             PERFORM emit.
  gv_line = |OPSYS={ sy-opsys }|.             PERFORM emit.
  gv_line = |HOST={ sy-host }|.               PERFORM emit.
  gv_line = |CLIENT={ sy-mandt }|.            PERFORM emit.

  " ---- 2. 组件清单：SELECT * 全字段（规避版本结构差异），
  "         SP 级别列动态读取（不同版本列名不同，存在才输出）----
  gv_line = '=== SECTION2_COMPONENTS'.        PERFORM emit.
  PERFORM read_cvers.

  " ---- 3. 关键函数模块存在性（ADT-over-RFC / RFC 读表 / 指纹）----
  gv_line = '=== SECTION3_FM_EXIST'.          PERFORM emit.
  PERFORM fm_exist USING 'SADT_REST_RFC_ENDPOINT'.  " ADT RFC 承载（二期第二传输栈前置）
  PERFORM fm_exist USING 'RFC_READ_TABLE'.          " RFC 读表通道依赖
  PERFORM fm_exist USING 'RFC_SYSTEM_INFO'.         " RFC 指纹探测依赖
  PERFORM fm_exist USING 'BBP_RFC_READ_TABLE'.      " 部分系统的备用读表 FM

  " ---- 4. 对象类型支持面（RAP 时代对象在低版本是否存在）----
  " TADIR 全版本存在，静态查询安全；COUNT=0 表示该对象类型在本系统不存在。
  gv_line = '=== SECTION4_OBJECT_TYPES'.      PERFORM emit.
  PERFORM tadir_count USING 'BDEF'.   " RAP 行为定义
  PERFORM tadir_count USING 'SRVD'.   " 服务定义
  PERFORM tadir_count USING 'DDLS'.   " CDS DDL 源
  PERFORM tadir_count USING 'DCLS'.   " CDS 访问控制
  PERFORM tadir_count USING 'STOB'.   " STOB（结构化对象）

  " ---- 5. 版本敏感表存在性与规模：表不存在 = 重要版本事实 ----
  gv_line = '=== SECTION5_TABLE_EXIST'.       PERFORM emit.
  PERFORM table_count USING 'DDLSRC'        'DDLSRC_ROWS'.    " CDS DDL 源（7.40 SP05+）
  PERFORM table_count USING 'DDLDEPENDENCY' 'DDLDEP_ROWS'.   " CDS 依赖（7.40+）
  PERFORM table_count USING 'E070'          'E070_ROWS'.      " 传输请求头
  PERFORM table_count USING 'E071'          'E071_ROWS'.      " 传输对象
  PERFORM table_count USING 'CVERS_731'     'CVERS731_ROWS'.  " 组件扩展表（7.31+）

  " ---- 6. 全文一键复制 ----
  PERFORM copy_or_download.

* 统一输出：写屏幕列表 + 收集到内表（结尾整体进剪贴板/文件）
FORM emit.
  WRITE: / gv_line.
  APPEND gv_line TO gt_report.
ENDFORM.

FORM read_cvers.
  DATA: lt_cvers TYPE STANDARD TABLE OF cvers,
        ls_cvers TYPE cvers.
  SELECT * FROM cvers INTO TABLE lt_cvers.
  LOOP AT lt_cvers INTO ls_cvers.
    " COMPONENT / RELEASE 两列全版本存在，静态读
    gv_line = |COMP={ ls_cvers-component } REL={ ls_cvers-release }|.
    PERFORM emit.
    " SP 级别相关列按常见列名依次动态尝试：存在哪个输出哪个
    PERFORM write_field USING ls_cvers 'EXTRELEASE' 'EXTREL='.
    PERFORM write_field USING ls_cvers 'SPLEVEL'    'SP='.
    PERFORM write_field USING ls_cvers 'PATCHLEVEL' 'PL='.
    PERFORM write_field USING ls_cvers 'DESCRIPT'   'DESC='.
  ENDLOOP.
ENDFORM.

FORM write_field USING value(is_struct) TYPE any
                       value(iv_field)  TYPE c
                       value(iv_prefix) TYPE c.
  FIELD-SYMBOLS: <lv_field> TYPE any.
  ASSIGN COMPONENT iv_field OF STRUCTURE is_struct TO <lv_field>.
  IF sy-subrc = 0.
    gv_line = |  { iv_prefix }{ <lv_field> }|.
    PERFORM emit.
  ENDIF.
ENDFORM.

* FM 存在性：只用 EXCEPTIONS 判定（存在 sy-subrc=0，不存在 function_not_exist）。
* 不读 IMPORTING 参数——不同版本 FUNCTION_EXISTS 的 IMPORTING 参数名有差异，
* EXCEPTIONS 面全版本稳定。
FORM fm_exist USING value(iv_name) TYPE rs38l_fnam.
  CALL FUNCTION 'FUNCTION_EXISTS'
    EXPORTING
      funcname           = iv_name
    EXCEPTIONS
      function_not_exist = 1
      OTHERS             = 2.
  IF sy-subrc = 0.
    gv_line = |FM={ iv_name } EXIST=YES|.
  ELSE.
    gv_line = |FM={ iv_name } EXIST=NO|.
  ENDIF.
  PERFORM emit.
ENDFORM.

* R3TR 对象类型全库计数
FORM tadir_count USING value(iv_object) TYPE trobjtype.
  SELECT COUNT(*) FROM tadir INTO gv_count
    WHERE pgmid = 'R3TR' AND object = iv_object.
  gv_line = |TYPE={ iv_object } COUNT={ gv_count }|.
  PERFORM emit.
ENDFORM.

* 动态表计数：先经 DD02L 验证是活动透明表，不存在输出 NOT_EXIST（=版本事实）
FORM table_count USING value(iv_tab)   TYPE dd02l-tabname
                       value(iv_label) TYPE c.
  SELECT SINGLE tabname FROM dd02l INTO gv_tab
    WHERE tabname = iv_tab AND tabclass = 'TRANSP'.
  IF sy-subrc <> 0.
    gv_line = |{ iv_label } = NOT_EXIST|.
    PERFORM emit.
    RETURN.
  ENDIF.
  SELECT COUNT(*) FROM (iv_tab) INTO gv_count.
  gv_line = |{ iv_label } = { gv_count }|.
  PERFORM emit.
ENDFORM.

* 结尾：全文写入 Windows 剪贴板；失败回退另存为 txt。
* cl_gui_frontend_services 的方法用经典 EXCEPTIONS（不是类异常），必须声明防 dump。
FORM copy_or_download.
  CALL METHOD cl_gui_frontend_services=>clipboard_export
    CHANGING
      data            = gt_report
    EXCEPTIONS
      cntl_error      = 1
      error_no_gui    = 2
      dp_error_create = 3
      dp_error_send   = 4
      OTHERS          = 5.
  IF sy-subrc = 0.
    gv_line = '=== REPORT_COPIED_TO_CLIPBOARD：全文已复制到剪贴板，直接 Ctrl+V 粘贴发送'.
    PERFORM emit.
  ELSE.
    PERFORM save_to_file.
  ENDIF.
ENDFORM.

FORM save_to_file.
  DATA: lv_filename TYPE string,
        lv_path     TYPE string,
        lv_fullpath TYPE string,
        lv_action   TYPE i.
  CALL METHOD cl_gui_frontend_services=>file_save_dialog
    EXPORTING
      default_extension = 'txt'
      default_file_name = 'low_release_facts'
    CHANGING
      filename          = lv_filename
      path              = lv_path
      fullpath          = lv_fullpath
      user_action       = lv_action
    EXCEPTIONS
      cntl_error        = 1
      error_no_gui      = 2
      OTHERS            = 3.
  IF sy-subrc <> 0 OR lv_action = cl_gui_frontend_services=>action_cancel.
    gv_line = '=== EXPORT_FAILED：请手动全选复制（Ctrl+Y 全选，Ctrl+C 复制）'.
    PERFORM emit.
    RETURN.
  ENDIF.
  CALL METHOD cl_gui_frontend_services=>gui_download
    EXPORTING
      filename = lv_fullpath
      filetype = 'ASC'
    CHANGING
      data_tab = gt_report
    EXCEPTIONS
      OTHERS   = 1.
  IF sy-subrc = 0.
    gv_line = |=== REPORT_SAVED_TO_FILE: { lv_fullpath }|.
  ELSE.
    gv_line = '=== EXPORT_FAILED：请手动全选复制（Ctrl+Y 全选，Ctrl+C 复制）'.
  ENDIF.
  PERFORM emit.
ENDFORM.
```

> v3 运行结束看最后几行的提示：`REPORT_COPIED_TO_CLIPBOARD` = 全文已进剪贴板，
> 直接 Ctrl+V 粘贴发送；`REPORT_SAVED_TO_FILE` = 已导出 txt，发送文件内容即可。
> 输出中的 `NOT_EXIST` 行请原样保留——例如 `DDLSRC_ROWS = NOT_EXIST` 直接说明
> 目标系统低于 7.40 SP05（无 CDS），是版本定性的关键证据。

## 方式 C：手工核对项（SAP GUI 逐项，共 6 项）

| # | 位置 | 核对内容 | 为什么需要 |
|---|---|---|---|
| 1 | SICF | `/default_host/sap/bc/adt` 节点是否存在且激活 | ADT 后端可用性（M0 验收的一半） |
| 2 | SICF | `/default_host/sap/bc/apc` 节点是否存在 | WebSocket 桥 / git.abapgit 前置（M3） |
| 3 | Eclipse ADT | 用 Eclipse 连一次目标系统，能否连上、哪些工程向导可用 | ADT 面真值的黄金标准：Eclipse 能连 = ADT REST 能用 |
| 4 | STRUST | SSL Client (Standard) PSE 的证书链状态 | abapGit 外发 HTTPS（git.abapgit 桥，M3） |
| 5 | SE80 | Object Type 树中搜 `BDEF`/`SRVD`，确认缺席 | 与报表 SECTION4 互证 RAP 对象类型缺席 |
| 6 | SE09/STMS | 传输组织器正常打开、能看请求列表 | 受控传输链（M2 降级路径）前置 |

## 优先级

1. **先跑方式 B 报表**（5 分钟，覆盖指纹/组件/对象面/FM 存在性约 80% 的信息量）。
2. 方式 C 的第 1、3 项（SICF adt 节点 + Eclipse 连一次）是次高优先级——直接定 M0 验收。
3. 其余手工项在 M2/M3 对应里程碑前补齐即可。
4. 如果能给方式 A 的连接信息，方式 B/C 大部分可由我代收，只留 Eclipse 项需要人看。
